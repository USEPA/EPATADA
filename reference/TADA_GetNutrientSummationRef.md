# Nutrient Summation Reference Key

Function downloads and returns the newest available nutrient summation
reference dataframe. This dataframe is used in
TADA_CalculateTotalNitrogen as the basis for the combinations added
together to get total nitrogen. Users may customize this reference table
for their own dataset and use the custom dataframe as an input in
TADA_CalculateTotalNitrogen.

## Usage

``` r
TADA_GetNutrientSummationRef()
```

## Value

Dataframe of nutrient summation combinations
