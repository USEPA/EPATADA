# correctColType (UNDER ACTIVE DEVELOPMENT)

This function corrects the column data types for TADA, ATTAINS and User
Ref data to ensure all TADA functions can function correctly.

## Usage

``` r
correctColType(.data)
```

## Arguments

- .data:

  A data frame containing columns required for TADA functions.

## Value

A data frame with correct column data types to use TADA functions.
