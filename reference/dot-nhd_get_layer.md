# .nhd_get_layer

Helper function for fetchNHD to get a layer from the opened map service
for NHD hi res.

## Usage

``` r
.nhd_get_layer(nhd, id)
```

## Arguments

- nhd:

  The opened map service object returned by .nhd_arc_open(url).

- id:

  Integer argument. The layer ID inside the HR map server.
