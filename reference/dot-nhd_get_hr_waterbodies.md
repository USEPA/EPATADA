# nhd_get_hr_waterbodies

Sends a set of AOIs to the NHD HR waterbody service and returns matching
high-resolution waterbody features.

## Usage

``` r
.nhd_get_hr_waterbodies(nhd_hr_waterbodies, geospatial_aoi)
```

## Arguments

- nhd_hr_waterbodies:

  An ArcGIS layer or object representing the NHD HR waterbodies dataset.

- geospatial_aoi:

  A list or vector of spatial features representing AOIs to query.
