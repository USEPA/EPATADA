# Create and download .csv

This function creates a .csv file and exports it to a user's download
folder with the name of the data frame as the file name.

## Usage

``` r
TADA_CreateCSV(.data)
```

## Arguments

- .data:

  A data frame.

## Examples

``` r
if (FALSE) { # \dontrun{
# Returns a .csv file of the example Data_Nutrients_UT TADA data frame.
TADA_CreateCSV(Data_Nutrients_UT)
} # }
```
