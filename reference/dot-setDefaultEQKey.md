# .setDefaultEQKey

Get default EPATADA package rExpertQuery API key. For best performance
and to avoid server failures from rate-limits, EPATADA users should
obtain their own rExpertQuery API Key here:
https://owapps.epa.gov/expertquery/api-key-signup

## Usage

``` r
.setDefaultEQKey()
```

## Value

Character string. The default rExpertQuery API key.
