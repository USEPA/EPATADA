USGS dataRetrieval Elements

Comparing what fields (elements) are returned with dataRetrieval::readWQPdata dataProfile calls (see readWQPdata help for options for both Legacy and WQX3).

Example readWQPdata query

USGS site (USGS-440504121435800). Note as of 5/13/2025 the beta version of WQP was only returning USGS data, not WQX data. The Portal team are aware and working on it. Will query data and return different profiles types (e.g., ‘resultPhysChem’ vs ‘fullPhysChem’)

Join Legacy and Beta field elements using crosswalk table

Read in WQX crosswalk table to join the basic (legacy) and full (beta) field elements together to compare. Had to modify the crosswalk table to replace special characters in the legacy column (WqxV2.FieldName) so that they will match fields returned in dataRetrieval. For example, ‘ActivityStartTime/Time’ in crosswalk table vs ‘ActivityStartTime.Time’ from dataRetrieval.
